# Quarry UI

Free, open source React components and templates, distributed as a [shadcn registry](https://ui.shadcn.com/docs/registry).
Components are styled only with shadcn theme tokens, so they follow the host project's colors and dark mode.

## Structure

```
registry.json            Registry manifest (one entry per component)
registry/quarry/*.tsx    One self contained file per component (this is what users install)
registry/demos.tsx       Site only: maps each item to its live preview
public/r/*.json          Generated by `npm run registry:build`
app/                     Documentation site (gallery + component pages)
components/site/         Site chrome (header, sidebar, preview stage, prompts menu)
lib/                     Registry helpers, prompt builder, syntax highlighting
assets/brand/            Original brand artwork
```

## Develop

```bash
npm run dev
```

## Add a component

1. Create `registry/quarry/<name>.tsx`. Use theme tokens only (`bg-card`, `text-muted-foreground`, `text-primary`, `bg-chart-1` and so on), export a named component and accept `className`.
2. Add an entry to `registry.json` with its `dependencies`, `docs` usage snippet and `meta.stage` (`center` for small items, `fill` for sections).
3. Add it to `registry/demos.tsx`.
4. Run `npm run registry:build` to regenerate `public/r`.

## Install a component (users)

```bash
npx shadcn@latest add https://quarry-ui.com/r/<name>.json
```

Set `NEXT_PUBLIC_SITE_URL` to your deployed origin so install commands and prompts point at the right registry.
